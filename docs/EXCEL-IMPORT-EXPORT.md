# تقرير Excel Import/Export (PHASE 48)

## ما تم بناؤه

### التصدير (Export) — 4 وحدات
كل تصدير كيولّد ملف `.xlsx` حقيقي (مو CSV مموّه) بـ`exceljs`، برأسية ملوّنة بنفس هوية النظام:
- **المنتجات**: مرجع، اسم، فئة، ماركة، وحدة، تكلفة متوسطة، سعر بيع، حد أدنى، نقطة إعادة الطلب
- **المخزون**: الرصيد الفعلي، المحجوز، المتوفر، صحة المخزون — نفس الأرقام المعروضة فـ`/stock`
- **المبيعات**: كل طلبات البيع بحالتها وإجماليها
- **المشتريات**: كل طلبات الشراء بحالتها وعملتها

### الاستيراد الجماعي (Import) — منتجات
**هاذا الجزء الأهم**، لأنه كيحل مشكل حقيقي: إدخال مئات المنتجات يدوياً واحد واحد.

- **نموذج جاهز للتحميل** (`/api/excel/products/import-template`) — يبين بالضبط الأعمدة المطلوبة مع مثال حقيقي
- **تحقق صارم**: الملف يُرفض فوراً إذا ماكانش صيغة xlsx صالحة، أو إذا الأعمدة الإلزامية (`internalRef`, `name`) ناقصة
- **معالجة سطر-بسطر بدون توقف كامل**: سطر واحد فيه خطأ ما كيوقفش باقي الاستيراد — كل سطر يتعالج لوحده
- **منع الازدواجية**: مرجع داخلي موجود مسبقاً كيتـتجاهل السطر (مو كيكتب فوقو) مع تسجيل السبب
- **تقرير حقيقي بعد الاستيراد**: عدد المُنشأ، عدد المُتجاهل، ولائحة كاملة بكل سطر فشل ورقم السطر والسبب بالضبط
- **Tenant isolation**: كل منتج جديد مرتبط تلقائياً بشركة المستخدم الحالي
- **Audit log**: عملية الاستيراد الجماعي مسجّلة بالكامل

تفصيل اختبارات `excel.service.spec.ts`:
- **تصدير حقيقي**: توليد الملف ثم **إعادة قراءته فعلياً** بـ`exceljs` للتأكد أنه xlsx صالح وليس bytes عشوائية — تحقق من الرأسية والبيانات الفعلية.
- **استيراد**: رفض ملف غير صالح، رفض ملف بدون الأعمدة الإلزامية، إنشاء الأسطر الصحيحة وتجاهل الأسطر الناقصة **بدون توقف كامل العملية**، منع الازدواجية مع تسجيل السبب، عزل الشركات، القيم الافتراضية (وحدة PCE، أصفار للحدود)، تسجيل سجل التدقيق.

## القيود
- **بدون Background Job** (كما طلبت المواصفات "Large imports: Background Job, Progress Bar") — الاستيراد حالياً متزامن (synchronous)، مقبول لملفات متوسطة الحجم (مئات الأسطر)، لكن ملف بآلاف الأسطر يحتاج معالجة غير متزامنة (queue) لتفادي timeout — مؤجل لمرحلة لاحقة.
- **الاستيراد الجماعي مبني فقط للمنتجات** — العملاء، الموردين، الرصيد الافتتاحي (المذكورين فPHASE 48 الأصلية) لسا ماكاينينش، لكن نفس النمط قابل للتكرار عليهم بسرعة.
- **لا معاينة قبل التأكيد** (Preview) — الاستيراد كيوقع مباشرة عند الرفع، بدون خطوة "راجع قبل التأكيد".
